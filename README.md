para poder utilizar nosso agente é no terminal necessario
1. Instala o pyton 3.12
2. Roda na raiz do projeto: python -m venv venv (Cria o ambiente virtual)
3. Roda .\venv\Scripts\Activate.ps1 (Ativa o ambiente)
4. Roda pip install -r requirements.txt (instala as bibliotecas necessarias)
5. Roda python -m tests.test_agent (Inicia o agente no cmd)
